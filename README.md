# TAIKI
TAIKI soll elf Engineering-Skills in ein einheitliches, kontrollierbares Modell integrieren. Jede Ausführung erzeugt neben dem Ergebnis ein Evidence Pack, das Quellen, Messwerte, Schwellenwerte, Abweichungen, Risiken und Entscheidungen für einen unabhängigen Controller-Agenten nachvollziehbar macht.
