# TAIKI Roadmap

This roadmap captures intended scope, not a claim that each capability is already implemented. Delivery dates and scope may change as requirements and validation mature.

| Version | Planned scope |
| --- | --- |
| v1.0 | Controller agent, MetricsDB foundation, and eleven engineering skills |
| v1.1 | Grafana and Power BI integrations |
| v1.2 | Multi-agent controller |
| v2.0 | TAIKI marketplace, plugin model, and skill registry |

## Near-Term Order

1. Finalize controller JSON contracts and compatibility policy.
2. Validate the MetricsDB model against representative runs.
3. Complete and review the eleven skill packages.
4. Replace placeholder CI checks with executable validation.
5. Connect dashboards to a supported production data source and validate their metrics.
