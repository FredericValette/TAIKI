# Agentic Test Automation

Translate an accepted test objective into bounded, reproducible automated checks.

## Workflow

1. Confirm the behavior, environment, test data, and allowed actions.
2. Map requirements to test cases and identify coverage gaps.
3. Execute only approved tests; preserve logs and distinguish infrastructure failures.
4. Report pass, fail, blocked, and not-assessed outcomes with evidence.

Do not modify production data or broaden test scope without authorization. Use `prompts/assessment.prompt.md` and `references/output-contract.md`.
