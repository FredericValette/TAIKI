# Skill Gap Analysis

Compare required capabilities with available, evidenced skills and identify practical development options.

## Workflow

1. Confirm roles, work horizon, capability taxonomy, and privacy constraints.
2. Gather only relevant, consented, and appropriately aggregated evidence.
3. Compare required and available capability levels; mark unknowns explicitly.
4. Recommend training, pairing, hiring, or workload changes with review dates.

Do not infer individual capability from sensitive or unrelated personal data. Use the prompt and output contract in this directory.
