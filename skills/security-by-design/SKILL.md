# Security by Design

Identify material security risks in the specified design and map them to practical, verifiable controls.

## Workflow

1. Confirm system scope, data sensitivity, actors, and trust boundaries.
2. Identify assets, entry points, threats, and abuse scenarios.
3. Map existing and proposed controls to risks and verification evidence.
4. Prioritize residual risks and remediation actions; record assumptions.

Do not claim a system is secure from a document-only review. Use the prompt and output contract in this directory.
