# Software Landscape Assessment

Map the in-scope applications, runtimes, frameworks, dependencies, hosting, ownership, and support lifecycle.

## Workflow

1. Confirm scope, systems, evaluation date, and available sources.
2. Inventory technologies and versions; distinguish verified facts from estimates.
3. Flag unsupported, end-of-life, duplicated, and unknown components with evidence.
4. Summarize lifecycle exposure and prioritized follow-up actions.

Do not infer versions or support status without a dated source. Use `prompts/assessment.prompt.md` and return findings following `references/output-contract.md`.
