# Architecture Discovery

Describe the current architecture from observed repository, deployment, and operational evidence.

## Workflow

1. Confirm system boundaries and the architecture questions to answer.
2. Identify components, interfaces, dependencies, data stores, and trust boundaries.
3. Trace important flows and label unknown or inferred relationships.
4. Record constraints, risks, and evidence-backed improvement options.

Do not present a proposed target architecture as the current state. Use `prompts/assessment.prompt.md` and `references/output-contract.md`.
