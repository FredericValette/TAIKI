# Release Readiness DQA

Evaluate whether a release has sufficient quality evidence and controlled residual risk.

## Workflow

1. Confirm release scope, criteria, owners, and assessment window.
2. Map each mandatory quality gate to evidence and an explicit result.
3. Record failed, missing, stale, and not-applicable evidence separately.
4. Apply the controller decision rules and produce owned, dated actions.

Never treat an unmeasured gate as passed. Align decisions with `controller/policies/` and use the output contract below.
