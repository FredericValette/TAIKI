# TAIKI Skills

Each skill package contains a `SKILL.md`, an execution prompt, output guidance, a JSON input schema, and a sample input. The packages define assessment workflows; they do not imply that external systems are connected or that assessments have already been executed.

| Skill | Focus |
| --- | --- |
| `software-landscape-assessment` | Technology inventory and lifecycle |
| `architecture-discovery` | Components, boundaries, and flows |
| `visual-testing-playwright` | Reproducible visual checks |
| `agentic-test-automation` | Bounded test planning and execution |
| `release-readiness-dqa` | Evidence-based release gates |
| `technology-radar` | Technology option assessment |
| `skill-gap-analysis` | Team-level capability gaps |
| `security-by-design` | Threats and design controls |
| `performance-capacity-analytics` | Measured performance and capacity |
| `ticket-intelligence` | Ticket quality and triage |
| `executive-engineering-copilot` | Evidence-linked leadership summaries |
